# 原生面板包含哪些许可证

`native-build.json` 的 `inputFiles` 列出了构建后随 LessonWeave 分发的原生面板、分块代码和资源依赖。下表按这些文件实际引用的 package root 收集版本与许可信息；每个包的原版 LICENSE、NOTICE 或 COPYING 文件保存在对应目录中，并保留原有版权文字。相同许可证仍按包名分别列出，方便逐项核对。

`readweave/LICENSE` 保存 ReadWeave 源码根目录的 AGPL 许可证。npm 包 `blurhash` 没有附带许可证文件；这里保留了 [Wolt 官方仓库的 License.md](https://raw.githubusercontent.com/woltapp/blurhash/master/License.md)。
