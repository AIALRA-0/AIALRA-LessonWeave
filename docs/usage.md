# 1 第一次运行前要准备什么

LessonWeave 可以处理网页、PDF 和项目 ZIP。先准备 Python 3.11 或更新版本；如果电脑还没有 Codex CLI，再准备 Node.js 20 或更新版本，让安装器按需安装官方 CLI 并启动设备登录。网页归档需要 Docker 正在运行；需要英译中翻译时，请在环境变量 `AIALRA_DEEPSEEK_OFFICIAL_KEY` 或 `LESSONWEAVE_DEEPSEEK_KEY` 中设置 DeepSeek 官方密钥。

写作和规划会使用当前配置的模型额度；首次生成自编样例也会发起真实模型调用；如果你只想浏览页面，可以直接打开仓库提供的内置架构案例

## 2 怎样从网站提交材料

如果你只想先浏览工作台和内置案例，可以不用生成新读本；如果要提交材料，先在仓库根目录运行安装器：

```bash
# 安装依赖并启动本地工作台
python deploy/bootstrap.py
```

安装器会在浏览器中打开 `http://127.0.0.1:8960/workspace`；选择或新建一个文件夹，点击“生成读本”，再选择网页、PDF 或项目 ZIP 并提交；网页归档需要 Docker；PDF 默认使用 Docling，也可以在部署时选择 PyMuPDF 路径

任务运行时，工作台会显示当前阶段、已完成的内容、正在运行或排队的调用、已用时间，以及已经保存的结果。生成结束后，读本会在同一工作台打开；你可以切换章节、查看原文与译文、回到网页段落或 PDF 页面、搜索正文和术语，并保存学习笔记。接入 ReadWeave 后，正文以共享文章的只读版本显示；要修改正文，请使用文章上方的“在 ReadWeave 编辑当前文章”入口。原文与译文分别作为文章保存；在 LessonWeave 的原文或译文栏选中文字时，术语栏里的 ReadWeave 面板会切换到对应文章，后续操作沿用该文章的来源关系。PDF 默认使用 Docling；如果你部署时选择 `--without-docling`，系统会改用 PyMuPDF，详细步骤见[部署指南](deployment.md)。

## 3 怎样从命令行生成读本

输入 JSON 由 `00_source/input.schema.json` 约束，需要提供 `kind`、`material`、`mode` 和 `system_prompt`；相对文件路径按输入 JSON 所在目录解析；仓库提供网页、PDF 与代码示例：

```bash
# 使用仓库中的自编鸟类调查 PDF 生成读本
python -m lessonweave run --input examples/pdf.input.json --name "鸟类调查示例"
```

命令会建立新项目并输出项目标识与真实运行结果；之后可以把同一个项目标识传给 `--project` 继续使用已有项目；写作调用会消耗配置模型的额度；重复运行时，系统会复用已经保存的结果

要只运行问题规划或章节编排，可以使用 `python -m lessonweave plan <项目目录> --stage questions` 或 `--stage chapters`；命令只运行你指定的阶段，不会重写已经保存的正文和个人笔记；完整规则见[问题规划说明](question-planning.md)。

## 4 怎样理解进度和检查状态

当前流程有 13 个阶段；每个阶段的状态来自项目已经保存的结果；某个阶段尚未生成时，页面会显示“尚未生成”，不会提前填成成功

系统会分别显示材料内容是否提取、材料用途是否明确、应讲内容是否交给具体问题，以及正文是否引用本问负责的材料；每一项使用自己的统计范围；正文引用完整仍需要读者核对事实和解释；详细含义见[架构说明](architecture.md)

脚本发现具体的格式、字段或来源引用问题时，系统最多进行一轮批量修复；没有这类问题时不会调用修复模型。当前流程不会用 AI 给正文做语义质量评分；检查后仍有的问题会随读本保存，读者可以对照完整正文和原文自行判断解释是否准确。

## 5 怎样恢复、导出和保管数据

默认项目、原件、调用记录和笔记保存在用户目录下的 `.lessonweave`；设置 `LESSONWEAVE_DATA` 可以把它们放到你选择的持久目录；网站的停止按钮会保留已完成阶段；继续任务时，LessonWeave 会复用已有结果

从 CLI 导出阅读包时，把 `python -m lessonweave export <项目目录>` 中的 `<项目目录>` 换成当前项目的数据目录；导出的包包含读本、原件和来源映射，不包含个人学习笔记；工作台或已经配置的笔记库会继续保存这些笔记。

升级前先备份 LessonWeave 数据目录、数据库和仓库外的配置文件。VPS 服务、身份验证和反向代理的安装步骤见[部署指南](deployment.md)；如果由 Agent 协助部署，可以从[基础部署提示词](agent-deployment.md)开始。ReadWeave 目前支持的功能和已完成的检查见[交接说明](../integrations/readweave/HANDOFF.md)；公开离线读本案例的来源与下载状态见[案例包说明](examples.md)。
