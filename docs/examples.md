# 公开案例包里有什么

公开案例包把已经保存的阅读结果整理成可以离线打开的页面。你可以先看目录、连续正文、练习和术语，再用来源映射判断正文对应原材料的哪些页或文件；这份映射不能代替原件，也不能单独证明讲解正确。

## 从哪里取得案例包

`lessonweave-public-cases-0.1.0.zip` 保留案例数据版本 `0.1.0`；它与 ReadWeave 源码包一起放在 [v0.2.0 Release 页面](https://github.com/AIALRA-0/AIALRA-LessonWeave/releases/tag/v0.2.0)。案例包还附有一份 `minimal-web` 自编预览材料，读者下载 ZIP 后可以离线查看。

## 每个案例会包含什么

案例包包含 `web`、`pdf`、`code` 三本已完成读本，以及 `minimal-web` 预览示例。每本案例都提供一个离线 `index.html`、书稿 JSON、来源映射和案例说明；案例说明会分别写明保存状态、原件是否随包提供、已知的来源恢复方式和当前不能确认的事项。

| 案例 | 读本状态 | 随包保留的来源信息 |
|---|---|---|
| `web` | 已完成 | 记录原案例公开网址和材料位置，不附网页归档或原网页文件 |
| `pdf` | 已完成 | 保留页码与材料位置，不附原 PDF；目前没有可核实的公开下载链接 |
| `code` | 已完成 | 提供 OpenROAD 的 GitHub 仓库地址、引用文件和源码行数，并保留原输入目录里实际存在的 10 份许可证文件；不附完整源码树 |
| `minimal-web` | 预览 | 附上经过文本和图片元数据清理的自编 HTML 与 PNG；原存档没有把它标记为检查通过 |

案例包根目录还会有 `README.md` 和 `MANIFEST.json`；OpenROAD 许可证会按原来的目录结构放在 `code/licenses/OpenROAD/` 下。

网页、PDF 和 OpenROAD 案例只保留最终正文、媒体说明、练习、易错点、术语和材料位置映射。打包器不会带上 WACZ、原网页、原 PDF 或完整 OpenROAD 源码树。OpenROAD 案例会保留原输入目录里实际存在的根许可证和子目录许可证文件，避免把未授权的完整代码副本混进案例包。

`minimal-web` 是案例包内的自编预览材料。打包器只会带上经过文本与图片元数据清理的 HTML 和 PNG，并保留它原本的预览状态；原存档没有标记它通过检查，所以页面会提醒读者把它当作流程示例。

## 原材料怎样重新取得

`web` 案例记录它的公开来源网址，但网页内容可能已经变化。`code` 案例指向 OpenROAD 上游仓库；原案例没有保留源码提交号，因此重新克隆当前默认分支不能保证与输入版本逐字相同。`pdf` 案例只记录了原 PDF 的本机地址，打包时会删除该地址；目前没有可核实的公开下载链接，重新阅读时需要自行提供有权使用的 PDF。

这些案例包展示的是已保存阅读结果，不是第三方材料的完整再发布。请在自行重取材料前检查来源网站和项目当时的授权条件。

## 哪些本地信息会排除

打包器只读取最终书稿、书稿引用的小节和来源定位清单。它排除模型提示词与回执、调用历史、个人笔记、运行状态、Cookies、私有路径、账号凭据、原始第三方网页归档、PDF 和源码树。打包前还会递归处理 JSON 字符串与 HTML 文本，过滤本机路径、内部主机、邮箱和凭据样式字段；它不会修改原案例，也不会启动模型。

公开覆盖数字仍只代表保存、材料去向、问题分配或来源映射等各自的记录；它们不表示阅读质量评分，也不能替代读者核对原文。
