# 1 新任务怎样进入正式流程

命令行和网站都把新任务交给 `lessonweave.pipeline.run`，该入口再调用 `lessonweave.lean.run`；详细的 13 个阶段由[架构说明](architecture.md)记录；阶段页面会读取当前任务已经保存的结果

命令行可以从一个输入 JSON 建立项目：

```bash
# 使用仓库中的网页示例输入创建学习项目
python -m lessonweave run --input examples/web.input.json --name "网页学习示例"
```

网站会在工作台中创建同类任务；任务提交后，后台继续处理；关闭页面不会删除已经保存的材料、调用记录或正文

## 2 哪些内容会复用

每个新问题使用一次写作调用生成短骨架、连续正文和附加内容；已完成的调用会在恢复或重新装配时复用；翻译会按原句去重，只有来源文本变化或缓存记录不匹配时才重新请求

正文全部完成后，系统依据实际答案集中生成承上启下；脚本随后执行独立检查；没有发现具体问题时跳过修复调用，有问题时最多执行一轮批量修复

## 3 怎样停止并继续任务

工作台的“停止”会结束当前任务及其模型、解析子进程，并保留已经保存的阶段结果与调用回执；用户点击“继续”后，系统复用可用结果，并按实际问题继续处理

恢复任务不会重新生成已保存的正文，也不会因为同步规则而修改旧读本或用户笔记；项目数据默认保存在用户目录下的 `.lessonweave`；部署时可以用 `LESSONWEAVE_DATA` 指定其他持久目录

## 4 怎样查看每阶段的记录

阶段列表显示当前完成数、活动调用、等待情况、耗时和已保存结果；完整调用记录保存在项目数据目录的 `runtime/calls`，统计汇总保存在 `runtime/usage.json`；没有返回的 token 或缓存数据会按缺失单独记录

当前流程不自动执行正文语义质量评分；脚本记录的材料引用覆盖率说明来源是否对应到正文，读者仍可以从完整样章跳到原文位置，逐项核对事实与解释；用法见[使用指南](usage.md)，安装方式见[部署指南](deployment.md)
